Importar Órdenes y Novedades

Carga masiva de suscripciones, altas de sedes y novedades contractuales almacenadas en base de datos

Dos métodos de entrada

1. Importación por Excel o Archivo Plano

Excel (.xlsx, .xls) / CSV / TXT

Sube un archivo de cálculo Excel o archivo plano desde tu equipo. El backend lo procesa y persiste los registros directamente en la base de datos PostgreSQL.

Formatos soportados: XLSX, XLS, CSV, TXT, TSV · hasta 20 MB.

2. Consumo por Path de Carpeta en Servidor

Servidor backend / Red UNC

Consume directamente una carpeta compartida en el servidor donde se depositan los cortes de Siigo o novedades. Sin necesidad de subir archivos manualmente desde el navegador.

Ruta local del servidor o recurso compartido UNC/SMB configurado.
